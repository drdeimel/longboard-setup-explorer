# Theme

## Purpose
UI color and theme definitions for the Longboard Simulator.

## Ownership
UI styling and theming domain.

## Local Contracts
- All color values and theme tokens must be defined here.
- Components must consume these tokens rather than hardcoding color values.

## Work Guidance
- Use Tailwind CSS configuration or CSS variables for theme tokens.
- Keep the palette minimal and accessible (sufficient contrast).

## Verification
- Visual inspection of UI components to ensure consistent theming.
